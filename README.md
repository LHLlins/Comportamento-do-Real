# FastAPI Stock Predictor

This project implements a stock price prediction model using an LSTM neural network and exposes it via a FastAPI application. The model is trained on historical stock data to predict the next day's opening price based on the previous 90 days of data (Open, High, Low, Close, Adj Close, Volume).

## Setup and Installation

1.  **Clone the repository (if applicable):**
    ```bash
    # git clone <repository_url>
    # cd <repository_directory>
    ```

2.  **Create and activate a virtual environment (recommended):**
    ```bash
    python -m venv venv
    # On Windows
    # venv\Scripts\activate
    # On macOS/Linux
    # source venv/bin/activate
    ```

3.  **Install dependencies:**
    Make sure you have the model files (`model.h5`, `feature_scaler.pkl`, `target_scaler.pkl`) in the root directory. If not, you need to train a model first.
    ```bash
    pip install -r requirements.txt
    ```

## Training a New Model

To train the model using `petr4_treinamento.csv` (or your own similarly formatted CSV data):

1.  **Ensure `petr4_treinamento.csv` is present** in the root directory. The CSV should have columns: `Date,Open,High,Low,Close,Adj Close,Volume`. The `Date` column is not used for training but is expected in the CSV.

2.  **Run the training script:**
    ```bash
    python train_model.py
    ```
    This script will:
    - Load and preprocess the data.
    - Train the LSTM model.
    - Save the trained model as `model.h5`.
    - Save the feature scaler as `feature_scaler.pkl`.
    - Save the target scaler as `target_scaler.pkl`.

    The training process might take some time depending on your hardware and the number of epochs (currently set to 5 in `train_model.py` for quick demonstration, but was 100 in the original scripts).

## Running the FastAPI Application

Once the model (`model.h5`) and scalers (`feature_scaler.pkl`, `target_scaler.pkl`) are available in the root directory:

1.  **Start the Uvicorn server:**
    ```bash
    uvicorn main:app --reload
    ```
    The API will typically be available at `http://127.0.0.1:8000`.

## Using the API Endpoint

The main endpoint for predictions is `/predict`.

-   **Method:** `POST`
-   **URL:** `/predict`
-   **Request Body:**
    A JSON object with a single key `data`. The value of `data` must be a list containing exactly 90 elements. Each element must be a list containing exactly 6 floating-point numbers, representing the features for one time step in the following order: `Open, High, Low, Close, Adj Close, Volume`.

    **Example Request:**
    ```json
    {
      "data": [
        [19.99, 20.20, 19.69, 19.69, 18.08, 30182600.0],
        [19.80, 20.40, 19.70, 20.40, 18.73, 30552600.0],
        // ... (86 more entries) ...
        [16.10, 16.12, 16.00, 16.10, 16.06, 19011500.0]
      ]
    }
    ```
    *(Note: The example shows only 3 entries for brevity; a valid request needs 90.)*

-   **Success Response (200 OK):**
    A JSON object with the predicted opening price for the next time step.
    ```json
    {
      "predicted_open_price": 16.15
    }
    ```
    *(The actual value will vary based on the input and the model.)*

-   **Error Responses:**
    -   `422 Unprocessable Entity`: If the request body is malformed (e.g., wrong data types, incorrect list lengths).
    -   `503 Service Unavailable`: If the model or scalers could not be loaded by the server.

## Running Tests

To run the unit tests for the FastAPI application:

1.  Ensure `pytest` is installed (it's included in `requirements.txt`).
2.  Make sure the model files (`model.h5`, `feature_scaler.pkl`, `target_scaler.pkl`) are present in the root directory, as the tests load the live application.
3.  Run pytest from the root directory:
    ```bash
    pytest test_main.py
    ```

    Some tests related to successful prediction might be skipped if the testing environment has issues loading the TensorFlow model or scalers correctly via the `TestClient`.
